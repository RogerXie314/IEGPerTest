# 白名单预览功能测试指南

## 快速测试步骤

### 1. 启动程序

```bash
dotnet run --project src/SimulatorApp
```

或直接运行编译后的 `SimulatorApp.exe`

### 2. 定位到白名单上传设置

在主界面右侧找到"程序白名单上传设置"模块。

### 3. 选择白名单文件

1. 点击"选择文件"按钮
2. 选择一个.wl文件（例如：`IEG-WorkstationDefender-res-wlFull_2_20231205172338.wl`）
3. 文件路径会显示在文本框中

### 4. 预览白名单

1. 点击"预览白名单"按钮（在"选择文件"按钮右侧）
2. 预览窗口会打开

### 5. 验证功能

**检查文件信息：**
- [ ] 文件名显示正确
- [ ] 文件版本显示（0xFEFE/0xFEFC/0xFEFB）
- [ ] 白名单数量显示
- [ ] 文件大小显示

**检查白名单列表：**
- [ ] 表格显示所有列（序号、文件名、路径、操作、Hash类型、Hash值）
- [ ] 数据正确显示
- [ ] 可以滚动查看所有记录

**测试搜索功能：**
- [ ] 在搜索框输入文件名（如"tipresx"）
- [ ] 列表实时过滤
- [ ] 显示匹配的记录数
- [ ] 点击"清除"按钮恢复全部显示

**测试导出功能：**
- [ ] 点击"导出列表"按钮
- [ ] 选择保存位置
- [ ] 文件成功保存
- [ ] 打开导出的文本文件验证内容

## 测试用例

### 测试用例1：正常文件

**文件：** `IEG-WorkstationDefender-res-wlFull_2_20231205172338.wl`

- 白名单数量：63,939 条

**预期结果：**

- 清除搜索后恢复全部显示

### 测试用例3：导出功能

**操作：** 导出前10条记录（搜索后导出）

**预期结果：**
- 导出文件包含文件信息
- 导出文件包含所有过滤后的记录
- 格式正确，可读性好

### 测试用例4：错误处理

**预期结果：**
- 显示友好的错误提示
- 程序不崩溃

## 已知限制

1. **V1格式**：暂不支持（需要实际V1文件测试）
2. **超大文件**：10万+条记录可能需要较长加载时间
3. **排序功能**：暂未实现列排序
