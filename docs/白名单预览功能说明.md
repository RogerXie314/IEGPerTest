# 白名单预览功能说明

## 功能概述

在"程序白名单上传设置"模块中新增了"预览白名单"按钮，可以在上传前预览.wl文件的内容，查看白名单数量和详细列表。

## 使用方法

### 1. 选择白名单文件

点击"选择文件"按钮，选择要上传的.wl文件。

### 2. 预览白名单

点击"预览白名单"按钮，打开预览窗口。

### 3. 预览窗口功能

**文件信息显示：**
- 文件名
- 文件版本（V2/V3/V4）
- 白名单数量
- 文件大小

**白名单列表：**
- 序号
- 文件名
- 完整路径
- 操作类型（添加/删除）
- Hash类型（SHA1/MD5）
- Hash值（PE Authenticode Image Hash）

**搜索功能：**
- 支持按文件名搜索
- 支持按路径搜索
- 支持按Hash值搜索
- 实时过滤显示

**导出功能：**
- 可将白名单列表导出为文本文件
- 包含完整的文件信息和所有条目

## 界面布局

程序白名单上传设置

## 技术细节

### 支持的文件格式

- **V2格式 (0xFEFE)**：最常见，包含基本字段
- **V3格式 (0xFEFC)**：扩展版，包含来源和判定方式
- **V4格式 (0xFEFB)**：最新版，包含所有字段

### Hash算法说明

白名单中的SHA1不是标准的文件SHA1，而是**PE Authenticode Image Hash**：
- 计算时排除了PE文件的CheckSum字段
- 计算时排除了数字证书部分
- 这样设计使得文件重新签名后Hash值不变
- 符合Windows代码签名标准

### 实现方式

**C#实现：**
- `WhitelistReader.cs`：白名单文件解析器
- `WhitelistPreviewWindow.xaml`：预览窗口界面
- `WhitelistPreviewViewModel.cs`：预览窗口逻辑
- 集成到`MainViewModel.cs`中

**Python工具（独立）：**
- `tools/wl_reader.py`：命令行工具
- `tools/wl_reader_gui.py`：独立GUI工具
- 可单独使用，不依赖主程序

## 使用场景

1. **上传前验证**
   - 确认白名单数量是否正确
   - 检查是否包含预期的文件

2. **问题排查**
   - 查看具体的白名单条目
   - 搜索特定文件或Hash

3. **文档记录**
   - 导出白名单列表供审查
   - 保存白名单快照

## 注意事项

1. **文件路径**：使用已选择的白名单文件，无需重新选择
2. **大文件**：6万+条记录可能需要几秒加载时间
3. **搜索性能**：实时搜索，大文件时可能有轻微延迟
4. **Hash类型**：显示的是PE Image Hash，不是标准文件Hash
