**Q [2026-05-07]: 编译报 int32_t 重定义错误，来自 ieg_protocal.cpp 引入 common/stdint.h 冲突**

A: 分析：common/wlModeEncrypt.h->Aes.h->brg_types.h->stdint.h（自定义pstdint，typedef int32_t），与MSVC <type_traits> 里的 int32_t 冲突。
解法：创建 ieg_aes_wrap.c（纯C文件），在纯C层 include wlModeEncrypt.h，把 wlModeCipherCtxInit_Len+wlEcbEncryptData 封装为 ieg_aes_ecb_encrypt()；ieg_protocal.cpp 只 include ieg_aes_wrap.h（无stdint依赖）和 sha1.h（自给自足，用 #define uint8/uint32）。

**Q [2026-05-07]: 编译链接报 sha1_starts/ieg_aes_ecb_encrypt 未解析**

A: 根因：CMakeLists.txt 里 project(NativeRunner LANGUAGES CXX) 只声明C++，.c文件被当C++编译，name mangling不匹配。修复：改为 LANGUAGES C CXX，重新cmake后编译成功。
