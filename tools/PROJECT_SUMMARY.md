# 白名单解析工具项目总结

## 项目背景

**需求：** 在上传白名单文件(.wl)到平台之前，需要能够预览文件内容，查看白名单数量和列表。

**问题：** 目前只能上传到平台后才能看到白名单列表，无法在本地预览。

**目标：** 创建一个工具，能够读取.wl文件，显示白名单列表及数量。

## 技术分析

### 1. 白名单文件格式分析

通过分析IEG原项目代码（`external/IEG_Code`），发现：

**关键文件：**
- `external/IEG_Code/code/worksheet_jni/worksheet.h` - 定义了白名单结构
- `external/IEG_Code/code/WLFileValidate/SystemHashStorage.cpp` - 实现了保存和加载逻辑

**文件格式：**
```
[2字节] 版本标识
  - 0xFEFF (V1)
  - 0xFEFE (V2)
  - 0xFEFC (V3)
  - 0xFEFB (V4)

[重复N次] 白名单条目:
  V4格式（最新）:
    [4字节] dwAddOrDel - 1=添加, 2=删除
    [4字节] dwIsSyetemFile - 是否系统文件
    [4字节] dwItemFrom - 来源
    [4字节] dwJudgeMethod - 判定方式
    [4字节] dwFullPathLength - 路径长度（字节）
    [变长] szFullPath - 文件路径（UTF-16LE编码）
    [4字节] dwHashType - 1=SHA1, 2=MD5
    [4字节] dwFileHashLength - Hash长度（字节）
    [变长] szFileHash - Hash值（UTF-16LE编码）
```

**关键发现：**
- 文件未加密（原代码中的加密仅用于system.dat等配置文件）
- 使用UTF-16LE编码存储字符串
- 支持多个版本格式，向后兼容

## 实现成果

### 1. 命令行工具 (wl_reader.py)

**功能：**
- 读取并解析.wl文件
- 显示文件信息（版本、数量）
- 列出白名单条目
- 导出到文本文件
- 支持限制显示数量

**使用示例：**
```bash
# 查看摘要
python wl_reader.py file.wl

# 查看所有条目
python wl_reader.py file.wl -l

# 查看前10条
python wl_reader.py file.wl -l -n 10

# 导出
python wl_reader.py file.wl -e output.txt
```


2. **运行命令行测试**
   ```bash

   ```

3. **运行GUI测试**
   ```bash
   python wl_reader_gui.py
   # 或双击 run_gui.bat
   ```

4. **验证结果**
   - 检查显示的数量是否正确（应该是6万多）
   - 检查路径和Hash值是否正确显示
   - 测试搜索功能
   - 测试导出功能

### 实际测试结果

对于示例文件 `IEG-WorkstationDefender-res-wlFull_2_20231205172338.wl`：
- 文件版本：0xFEFE (V2)
- 文件大小：20,588,636 字节
- 白名单数量：**63,939条**（不是9万，实际测试结果）
- 每条记录包含完整的路径和SHA1 Hash值
- 解析状态：✅ 成功

### 重要发现

**V2格式结构修正：**
初始分析时基于V4格式推测V2格式，但实际测试发现V2格式更简化：
- ❌ 错误假设：V2包含 dwIsSyetemFile 字段
- ✅ 实际结构：V2只有 dwAddOrDel + 路径 + Hash，不包含其他字段
- 这导致初次解析失败，修复后成功解析
